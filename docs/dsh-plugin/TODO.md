## 5. 有意保留的边界

- 安全目录捕获支持 Linux `/proc/self/fd` 与 Windows 固定 Win32 句柄。Windows 需要系统 PowerShell 与 `Add-Type`；其他平台尚未实现。当前 Windows 自动化及真实宿主模块集成已通过，运行中 GUI 的新版本加载仍需重新加载原 DSH 进程并核对。
- 兼容版本为实际验证的 DSH `0.2.1-rc.2` Web profile；其他 profile、外部 agent 后端和自定义 preset 需各自验证。
- 目录扫描有限额；临时镜像和同步校验会产生 CPU、内存与磁盘开销，实测数据见验证记录。
- 普通文件修改后缺少可靠操作者证据时报告来源不确定；“本次引入”证据路径在纯分类器测试中验证，没有宣称任意工具修改都能自动归责。
- 插件不新增系统任务结束或 Git 提交硬门禁；归档写入仍由 agent 自身权限约束的命令工具执行。
- 本轮不发布 npm、不推送远端、不保留正式长期部署。需要启用时按 [安装说明](../../README.md#dsh-插件一次启用覆盖各工作区) 操作。
